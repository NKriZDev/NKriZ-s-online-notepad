# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and the most recent published release. Older revisions may not receive fixes.

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue, discussion, pull request, or chat.

If this repository is hosted on GitHub, use the repository's **Security → Report a vulnerability** flow to submit a private security advisory. On another hosting service, contact the repository owner through a private channel and request a secure reporting method.

Include the affected revision, reproduction steps, expected impact, and any suggested mitigation. Do not include real passwords, recovery keys, plaintext vault data, or data belonging to other people.

## Scope

Reports involving authentication, encryption and key handling, cookie or origin protections, ciphertext storage boundaries, file upload/download integrity, recovery flows, backups, or accidental plaintext persistence are especially important.
